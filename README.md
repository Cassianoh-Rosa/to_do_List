# To do List

Projeto de uma lista de tarefas

## 🚀 Funcionalidades
- Cria a tarefa que desejar.
- Marca como concluida as tarefas feitas.
- pode ver apenas as tarefas pendentes
- pode ver apenas as tarefas concluidadas
- mostra quantas tarefas estão concluidas no total

## 🛠️ Tecnologias
- HTML
- CSS
- JavaScript
